# Smart Housing Inspection Dashboard V1

A Streamlit-based housing inspection dashboard developed in Python.

## V1 Scope

- Dashboard
- New Inspection
- Inspection Records
- Enforcement & Follow-up
- Analytics
- Reports & Export

## Technology

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
- fpdf2
- Pillow
- Google Colab for development

## Architecture

Google Colab
→ Python
→ Streamlit
→ Cloudflare Tunnel
→ Browser

## Data Storage

V1 uses CSV-based local storage.

Real inspection data and site photographs are excluded from GitHub.

## Development Workflow

PLAN → DESIGN → CODE → RUN → TEST → FIX → VERIFY → APPROVE → NEXT

## Project Status

V1 foundation and backend are under active development.
